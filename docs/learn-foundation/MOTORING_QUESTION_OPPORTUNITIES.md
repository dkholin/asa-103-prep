# Motoring question-bank opportunities

Step 4A does not add or change Practice questions. The accepted 34-question
mapping remains intact. These are future, separately scoped opportunities only.

| Area | Current direct coverage | Future opportunity |
|---|---|---|
| Engine instruments and alarms | One mapped question identifies the combined shift/throttle control; there is no direct question on tachometer, temperature, oil-pressure, or charging indications. | Add operator-awareness scenarios that distinguish the indication and the safe immediate response without testing repair diagnostics or universal thresholds. |
| Outboard neutral and shifting | Outboard type is represented, but neutral-before-start and low-rpm shifting are taught only in Learn. | Add one compact operating-sequence question if outboard handling becomes a larger Practice goal. |
| Outboard cooling telltale | No direct question. | Test recognition of missing cooling indication and the prompt-to-stop/investigate response, with a model-specific-manual caveat. |
| Engine-cutoff-switch link | No direct Motoring question. | Test purpose and operator attachment without overgeneralizing the federal applicability conditions. |
| Outboard tilt/trim | No direct question. | Test the difference between clearance/tilt and running-angle/trim, while making clear that controls and safe ranges vary by model. |
| Motoring etiquette and wake | No direct question. | Test wake reduction near docks and moored boats, obedience to posted/local restrictions, and predictable operation; do not invent a universal marina right-of-way rule. |

The sparse coverage is acceptable for this project and does not block the
finished Learn lessons.
