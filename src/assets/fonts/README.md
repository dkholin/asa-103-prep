# Font assets

These WOFF2 files are self-hosted application assets. Vite fingerprints and
rewrites their URLs from `src/styles.css`; the app makes no external font
requests at runtime.

- IBM Plex Sans Condensed Medium, SemiBold, and Bold (Latin WOFF2) came from
  the official Google Fonts distribution (`fonts.gstatic.com`, family version
  15) on 2026-08-26. The matching license text is
  `OFL-IBM-Plex-Sans-Condensed.txt`, from the `google/fonts` repository.
- Source Serif 4 Roman and Italic variable fonts (400–700, Latin WOFF2) came
  from the official Google Fonts distribution (`fonts.gstatic.com`, family
  version 14) on 2026-08-26. The matching license text is
  `OFL-Source-Serif-4.txt`, from the `google/fonts` repository.

Upstream license records:

- https://github.com/google/fonts/tree/main/ofl/ibmplexsanscondensed
- https://github.com/google/fonts/tree/main/ofl/sourceserif4
